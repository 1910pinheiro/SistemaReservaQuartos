# Sistema de Reserva de Quartos

## Status do Projeto
🚧 Em desenvolvimento

## Tecnologias Utilizadas
- Linguagem Java
- IDE NetBeans
- Banco de Dados MySQL
- Git e GitHub

## Time de Desenvolvedores
- Marcelo Paiva — aluno do curso

## Objetivo do Software
Gerenciar a reserva de quartos, permitindo agendar, consultar disponibilidade e controlar reservas de forma prática e organizada.

## Funcionalidades do Sistema
- Cadastro e consulta de quartos
- Realização e cancelamento de reservas
- Validação de horários e conflitos
- Interface gráfica com usuário
- Armazenamento dos dados no MySQL
